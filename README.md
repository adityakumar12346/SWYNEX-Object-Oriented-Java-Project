# SWYNEX Vehicle Rental Management System

A console-based Vehicle Rental Management System developed using Java as part of SWYNEX Technologies Task 2. This project demonstrates all four pillars of Object-Oriented Programming: Encapsulation, Inheritance, Abstraction, and Polymorphism.

## Features
- View all available vehicles.
- Rent cars and bikes.
- Calculate rental charges.
- Return rented vehicles.
- Track vehicle availability.
- Handle invalid inputs using exception handling.

## OOP Concepts Used
- **Encapsulation:** Private fields with getters and setters.
- **Inheritance:** Car and Bike extend the Vehicle class.
- **Abstraction:** Abstract Vehicle class and calculateRent() method.
- **Polymorphism:** Method overriding for vehicle-specific rental calculations.

## Technologies Used
- Java
- VS Code
- Git and GitHub

## How to Run

Compile the project:

```bash
javac Main.java Vehicle.java Car.java Bike.java RentalManager.java
```

Run the application:

```bash
java Main
```
